# Vishnu-CampusConnect-
Vishnu CampusConnect AI is a web dashboard &amp; Gemini-powered assistant for VITB &amp; SVECW students in Bhimavaram. Honoring Dr. B.V. Raju &amp; Smt. Sita Raju, it centralizes notices, tracks lab/exam deadlines, lists campus events, and provides instant Q&amp;A on library hours, buses, and placements using HTML5, Tailwind CSS &amp; LocalStorage.
